# GAAO Project Instructions

## What This Is

GAAO (General Adaptive Agent Ontology) is a formal ontology for adaptive agents. It was abstracted from ILA and is academically rigorous and domain-agnostic. Published as a preprint on Zenodo with DOI.

## Status

Published (v1.0). Not actively being developed. Deep intellectual work that Rob is passionate about, but acknowledged as an operational gravity trap — it can absorb unlimited time without serving the 3-5 year vision directly.

## When Working on GAAO

- This is academic/theoretical work, not product work
- Preserve rigour — GAAO's value is in its formal specification
- Do not conflate with ILA — GAAO is the general ontology, ILA is one instantiation
- Any future versions should maintain the Zenodo DOI chain
- The GitHub remote is `rswaab/gaao-spec` (historical name from initial publication)

## Structure

- `spec/` — the canonical v1.0 spec and LaTeX source
- `research/` — working papers on each GAAO layer
- `preprint/` — published PDF
- `arxiv/` — arXiv submission materials
- `instantiations/` — example domain instantiations
